## AUTO-IDEA GENERATION LOGIC

### What Claude Analyzes:

```
COMPANY INPUT:
- Name, sector, CSR focus, funding capacity, size, location
- Industry trends they're addressing
- Geographic presence (can connect locally)

COMPARISON TO BTS:
- Match company CSR focus to BTS streams
- Identify programs that teach relevant skills
- Size company's problem (cost, timeline, impact)
- Estimate funding needed vs company capacity

OUTPUT: 3-5 Partnership Ideas
- Why it aligns (CSR + education value + business benefit)
- Structure (how it works, deliverables, timeline)
- Streams/programs involved
- Budget + student impact numbers
- Difficulty (Easy = sponsorship; Hard = co-design lab)
- First contact angle (how to pitch)
```

## DATABASE STRUCTURE (How to Store This)

```sql
-- Streams (4 total)
CREATE TABLE streams (
  id INT PRIMARY KEY,
  name VARCHAR (Future of Communication, etc.),
  description TEXT,
  industry_focus VARCHAR (list of industries this serves)
);

-- Delivery Models (3 total)
CREATE TABLE delivery_models (
  id INT PRIMARY KEY,
  name VARCHAR (Future of Work, Design Sprint, Embedded),
  year_levels VARCHAR (7-8, 9-10, 9-12),
  duration_hours INT,
  student_capacity INT
);

-- Programs (30+)
CREATE TABLE programs (
  id INT PRIMARY KEY,
  name VARCHAR (Mic-Drop: 90-Second PodBite, etc.),
  stream_id INT (FK to streams),
  delivery_model_id INT (FK to delivery_models),
  description TEXT,
  tools_equipment VARCHAR (list),
  year_levels VARCHAR,
  student_count_capacity INT
);

-- Projects (20+)
CREATE TABLE projects (
  id INT PRIMARY KEY,
  name VARCHAR (Build & Bond, GenIUS, etc.),
  description TEXT,
  date_scheduled DATE,
  funding_status VARCHAR (Not funded, Funded, Grant-funded),
  budget DECIMAL,
  student_impact INT,
  related_streams VARCHAR (comma-separated stream IDs),
  related_programs VARCHAR (comma-separated program IDs)
);

-- Companies
CREATE TABLE companies (
  id INT PRIMARY KEY,
  name VARCHAR,
  sector VARCHAR,
  csr_focus TEXT,
  funding_capacity VARCHAR (Low/Medium/High/Very High),
  location VARCHAR,
  employee_count INT,
  tier INT (1-4)
);

-- Auto-Generated Partnership Ideas
CREATE TABLE partnership_ideas (
  id INT PRIMARY KEY,
  company_id INT (FK),
  idea_name VARCHAR,
  why_aligned TEXT,
  streams_involved VARCHAR (comma-separated stream IDs),
  programs_involved VARCHAR (comma-separated program IDs),
  delivery_models_involved VARCHAR,
  structure TEXT,
  estimated_budget DECIMAL,
  student_impact_number INT,
  student_impact_description TEXT,
  difficulty VARCHAR (Easy/Medium/Hard),
  first_contact_angle TEXT,
  generated_by VARCHAR (Claude),
  generated_date TIMESTAMP,
  status VARCHAR (Draft, Ready to Pitch, Pitched, Active Partnership)
);

-- Grants
CREATE TABLE grants (
  id INT PRIMARY KEY,
  title VARCHAR,
  funder VARCHAR,
  amount DECIMAL,
  deadline DATE,
  description TEXT,
  matched_streams VARCHAR (comma-separated stream IDs),
  matched_programs VARCHAR (comma-separated program IDs),
  matched_projects VARCHAR (comma-separated project IDs),
  fit_score INT (0-100),
  auto_generated_proposal TEXT,
  status VARCHAR (Not contacted, Researching, etc.)
);
```
